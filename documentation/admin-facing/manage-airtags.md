# Manage AirTags

Every hardware hand-off sends one of the committee's AirTags out with the hardware, so it can be found in Find My. The app doesn't talk to Find My; it only records which AirTag went with which loan.

1. From the admin home, open **AirTags** (under Inventory).
2. To add one, type its name exactly as it appears in Find My (for example `VRAR-01`), add an optional note (a keyring colour, a case), and press **Add AirTag**. Names must be unique.
3. Each AirTag shows **Free**, or **Out with** the item and member it went with. Press that to open the loan.
4. **Edit** renames an AirTag or changes its note. Loans keep the name the AirTag had when it went out.
5. **Remove** takes an AirTag out of the pool. It isn't possible while the AirTag is out with a loan.

At hand-off, the sign-off screen asks which free AirTag is going out with the hardware, and the hand-off can't be recorded without one. When the hardware comes back, the return screen names the AirTag to check for, and recording the return makes it free again.
